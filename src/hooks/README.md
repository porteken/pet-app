# Hooks

This folder contains shared custom React hooks used across the application.

## Guidelines

- Create reusable hooks that can be used by multiple features
- Follow React hooks naming convention (start with "use")
- Keep hooks focused on a single responsibility
- Include comprehensive tests for complex hooks
- Document hook parameters and return values

## Examples

Future hooks might include:

- `useLocalStorage`: Persist state to localStorage
- `useDebounce`: Debounce values for search functionality
- `useApi`: Generic API request hook
- `useAuth`: Authentication state management
